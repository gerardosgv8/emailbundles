# Landing Page Components

This directory contains React components that recreate the landing page from `index.html` using React and Tailwind CSS.

## Components

- **Header** - Navigation header with logo and menu
- **HeroSection** - Main hero section with headline and CTA
- **ProblemSolutionSection** - Problem/solution explanation
- **FeaturesGrid** - Key benefits grid
- **TemplatesGallery** - Template showcase
- **PricingSection** - Pricing information
- **TechnicalHighlights** - Technical features
- **DocsSection** - Documentation links
- **TestimonialsSection** - Customer testimonials
- **FAQSection** - Frequently asked questions
- **CheckoutSection** - Purchase form
- **Footer** - Site footer
- **LandingPage** - Main component that combines all sections

## Usage

The landing page is accessible at `/landing` route in the React app. All components use Tailwind CSS classes and maintain the same visual design as the original HTML version.

## Styling

- Uses custom `primary` color (`#0ea5e9`) defined in `index.css`
- Responsive design with mobile-first approach
- Consistent with the existing design system
